The project

More context
for each word.

The decks cover everyday vocabulary, words grouped by CILS level, numbers and verb forms. Some collections use lines from Italian films to put a word in context.

Cards include pictures and audio, with supporting details such as gender, plurals and word-for-word translations where relevant. The authoring combines dictionary reference data with AI-assisted text, pictures and recordings.

The website is plain static HTML. It groups the decks by purpose, shows real front-and-back examples, and links to Anki .apkg files with the media included.
